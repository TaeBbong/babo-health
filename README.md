# 헬스바보 - 운동 세트 수 카운트/기록 앱

![mockup image](doc/mockup.png)

## :rocket: 프로젝트 설명

- 헬스를 하다보면 내가 몇 세트까지 했더라 하고 까먹는 경우가 종종 있습니다.
- 이에 착안하여 아주 간단하게 세트 수를 카운트하고, 해당 운동을 기록할 수 있는 앱 서비스를 구현했습니다.
